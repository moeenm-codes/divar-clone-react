# دیوار فایل - Divar Files

این پروژه یک نمونه مشابه سایت دیوار است که با React.js پیاده‌سازی شده است.

## روند کار سایت (Workflow)

### 1. احراز هویت کاربر

- کاربر ابتدا باید وارد سایت شود
- ورود با شماره موبایل انجام می‌شود
- روند احراز هویت:
  1. وارد کردن شماره موبایل
  2. دریافت کد تایید (OTP)
  3. وارد کردن کد و تایید نهایی

### 2. دسترسی‌های کاربران

#### کاربر عادی:

- مشاهده لیست آگهی‌ها
- فیلتر کردن آگهی‌ها بر اساس دسته‌بندی
- ثبت آگهی جدید
- مدیریت آگهی‌های شخصی
- ویرایش و حذف آگهی‌های خود

#### کاربر ادمین:

- تمام قابلیت‌های کاربر عادی
- مدیریت تمام آگهی‌ها
- مدیریت دسته‌بندی‌ها
- حذف آگهی‌های نامناسب
- اضافه/ویرایش/حذف دسته‌بندی‌ها

### 3. شرایط و محدودیت‌ها

#### شرایط ثبت آگهی:

- کاربر باید لاگین کرده باشد
- عنوان آگهی حداقل 10 کاراکتر باشد
- توضیحات آگهی حداقل 20 کاراکتر باشد
- انتخاب دسته‌بندی اجباری است
- قیمت باید عدد معتبر باشد
- آپلود حداقل یک تصویر الزامی است

#### محدودیت‌های مسیریابی (Routes):

- `/` : صفحه اصلی (دسترسی عمومی)
- `/auth` : صفحه احراز هویت (فقط کاربران مهمان)
- `/dashboard` : پنل کاربری (فقط کاربران لاگین شده)
- `/admin` : پنل مدیریت (فقط ادمین)

### 4. ساختار پروژه

#### کامپوننت‌ها:

- `Templates/`: فرم‌ها و قالب‌های اصلی
- `modules/`: کامپوننت‌های عمومی و قابل استفاده مجدد
- `context/`: مدیریت state های عمومی برنامه
- `layouts/`: قالب‌های کلی صفحات

#### سرویس‌ها:

- `auth.js`: سرویس‌های مربوط به احراز هویت
- `admin.js`: سرویس‌های مدیریت
- `user.js`: سرویس‌های کاربری
- `token.js`: مدیریت توکن‌ها

### 5. نکات امنیتی

- استفاده از توکن JWT برای احراز هویت
- محافظت از مسیرهای حساس با `ProtectedRoute`
- ذخیره امن توکن در کوکی
- اعتبارسنجی تمام ورودی‌ها در سمت کلاینت و سرور
- جلوگیری از دسترسی غیرمجاز به پنل ادمین

### 6. مدیریت خطاها

- نمایش پیام‌های خطا با کامپوننت Toast
- هدایت کاربر به صفحه 404 در صورت آدرس نامعتبر
- نمایش لودر در زمان عملیات‌های زمان‌بر
- مدیریت خطاهای شبکه و API

## نیازمندی‌ها

- Node.js نسخه 14 یا بالاتر
- NPM یا Yarn
- دسترسی به اینترنت برای نصب پکیج‌ها

## راه‌اندازی پروژه

```bash
# نصب وابستگی‌ها
npm install

# اجرای پروژه در حالت توسعه
npm run dev

# ساخت نسخه نهایی
npm run build
```
